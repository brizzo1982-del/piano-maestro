# Piano Maestro

Web app per cellulari per imparare a suonare il pianoforte: 62 canzoni famose (rock, Queen, film, classica, folk, fiabe, feste), una nota alla volta, ognuna con il suo strumento (organo per L'Esorcista, synth anni '80 per Jump, chitarra distorta per Smoke on the Water…).

- **Ascolta**: la canzone suona da sola e mostra i tasti.
- **Impara**: le note scendono e la canzone aspetta che premi il tasto illuminato.
- **Sfida**: suona a tempo e guadagna fino a 3 stelle.
- **Suona libero**: tastiera di 3 ottave con 27 strumenti.

Tutti i suoni sono sintetizzati con Web Audio. Funziona offline dopo la prima visita e si può aggiungere alla schermata Home.

Online: https://brizzo1982-del.github.io/piano-maestro/
